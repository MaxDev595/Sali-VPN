# Sali VPN — структура бота и схема оплаты

Главный принцип: **деньги принимает только Telegram-бот.** Приложение из стора
(APK / App Store) ничего не продаёт: в нём нет цен, кнопок оплаты и Billing SDK —
только «Ввести код» и «Привязать Telegram».

## Путь клиента

```
Стор ──► приложение Sali VPN
          │ первый запуск: анимация лого → онбординг
          │ тихий вход: POST /auth/app {deviceKey} → Sali ID (SL-XXXX-XXXX)
          ▼
   «Привязать Telegram» ──► t.me/<bot>?start=link_<SaliID>     (фиксация клиента)
          ▼
   Бот: «🔗 Устройство SL-… привязано» + [🎁 Бесплатный тариф] [💎 Купить]
          ▼
   Оплата в боте (Stars / USDT TON / карта)
          ▼
   Бот присылает код SALI-XXXX-XXXX-XXXX  [📋 Скопировать] [⚡ Активировать на моём устройстве]
          ▼
   Приложение → «Ввести код» → POST /codes/redeem → подписка 30 / 365 дней
```

Если устройство привязано, код можно активировать прямо из бота одной кнопкой —
вводить его вручную не нужно. Код одноразовый, действует 90 дней и его можно подарить.

## Меню бота

| Кнопка / команда | Что делает |
|---|---|
| `/start` | регистрирует Telegram-аккаунт, показывает Sali ID и «Как это работает» |
| `/start link_<SaliID>` | привязывает приложение к этому Telegram (фиксация клиента) |
| `/start buy`, `/start free` | сразу открывает тарифы / бесплатный код (ссылки с сайта и Mini App) |
| 💎 Купить подписку `/buy` | тарифы месяц / год → выбор способа оплаты → код |
| 🎁 Бесплатный тариф `/free` | FREE-код (60 мин), один на Telegram-аккаунт навсегда |
| 🔑 Мои коды `/codes` | все коды: какие активированы и на каком устройстве |
| 📱 Мои устройства `/devices` | привязанные приложения и их тариф |
| 📲 Скачать приложение | ссылки на Google Play / App Store / APK |
| 👥 Пригласить друга | реферальная ссылка (+30 мин другу, −10% вам) |
| 💬 Поддержка `/help` | FAQ: как это работает, куда вводить код, привязка, оплата |
| ⚙️ Аккаунт `/account` | Sali ID, тариф, кнопка Mini App |
| текст `SL-XXXX-XXXX` | привязать ещё одно устройство |
| текст с кодом | кнопка «Активировать на моём устройстве» |

## Оплата

| Способ | Как работает | Как приходит код |
|---|---|---|
| ⭐ Telegram Stars | `sendInvoice` в XTR → `pre_checkout_query` → `successful_payment` | бот сразу в чате |
| 💵 USDT (TON) | счёт с суммой, адресом и комментарием, кнопка «Я оплатил — проверить» | автоматически от API после подтверждения сети |
| 💳 Карта (Paddle) | ссылка на защищённую страницу оплаты | автоматически от API после вебхука |

Включённые способы: `BOT_PAYMENT_METHODS=stars,crypto,card`.
Цена в звёздах: `STARS_PER_USD` или фиксированно `STARS_PRICE_PRO_MONTHLY`, `STARS_PRICE_PRO_YEARLY`.

## Уведомления (приходят привязанному Telegram)

- код активирован на устройстве SL-… (защита от кражи кода);
- за 3 дня до конца подписки — с кнопкой «💎 Купить код»;
- подписка / бесплатное время закончились — с кнопкой «💎 Купить код».

## API для бота (`/api/v1/internal/bot/*`, только по `X-Internal-Api-Key`)

`start`, `link`, `devices`, `plans`, `purchase`, `precheck`, `stars-paid`,
`payment-status`, `free`, `codes`, `apply`.

Публичный эндпоинт приложения: `POST /api/v1/auth/app`, `POST /api/v1/codes/redeem`
(5 попыток в минуту; код — 60 бит, подбор бесполезен).

## Модель данных

- `User.publicId` — Sali ID; `User.telegramId` теперь может быть пустым (аккаунт из стора);
  `User.appDeviceKey` — установка приложения; `User.linkedTelegramId` — кто её привязал.
- `ActivationCode` — `PAID | FREE | GIFT | PROMO`, статус `ISSUED | REDEEMED | REVOKED`,
  срок активации 90 дней, ссылка на платёж и на устройство, где активирован.
- `Payment.deliverAsCode` — платёж из бота превращается в код, а не в подписку.
- Тариф `pro_yearly` (365 дней, $40) добавлен в сид.

Миграция: `apps/api/prisma/migrations/20261103120000_activation_codes`.
