# Sali VPN: что сделано на 5 ноября 2026 и что дальше

База: коммит `5e28d8d` (main на GitHub, локальная копия совпадает).
Изменения лежат в `sali-wip-referrals.patch`, **НЕ применены и НЕ запушены**.
Применить: `git checkout -b wip/referrals-pricing && git am sali-wip-referrals.patch`

## Сделано (API, ещё не проверено сборкой)
- Рефералка: друг получает **+3 часа** (`REFERRAL_FRIEND_BONUS_HOURS`), пригласивший получает **10%** на следующую оплату (`REFERRAL_DISCOUNT_PERCENT`).
  - Связь записывается на `/start ref_<id>` только для нового Telegram-аккаунта (`bot-api.controller.ts` → `start`).
  - Бонус начисляется при первой активации кода другом (`codes.service.ts` → `redeem` → `referrals.rewardIfEligible`). +3 часа добавляются к триалу или к подписке на устройстве.
  - Скидка теперь работает и для Stars: `createStarsPayment` + `starsFor(plan, discount)`, проверяется в precheck. Старые неоплаченные Stars-счета освобождают скидку (`releaseStaleDiscounts`).
  - `/internal/bot/plans` принимает `telegramId` и отдаёт `discountPercent / discountedPriceUsd / discountedStars`; новый эндпоинт `/internal/bot/referrals`.
- Цены: в seed уже стоят $5 и зачёркнутая $8 (`originalPriceUsd`).
