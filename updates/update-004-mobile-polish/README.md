# Sali VPN 0.2.0

Обновление мобильного приложения с улучшением плавности интерфейса и пробного периода.

Версия приложения: `0.2.0`  
Android versionCode: `11`

## Что изменено

- убрана вступительная анимация логотипа перед онбордингом;
- добавлены плавные переходы контента между страницами онбординга;
- жёлтый индикатор онбординга плавно перемещается от первой точки к последней;
- добавлен счётчик бесплатного времени от `01:00:00` до `00:00:00`;
- счётчик синхронизируется с API, сохраняет остаток после перезапуска и списывает время только при активном VPN;
- ссылки на политику конфиденциальности и условия использования открывают документы на лендинге;
- версия приложения в настройках берётся из реальной Expo-конфигурации;
- добавлена переменная `EXPO_PUBLIC_LANDING_URL` для адреса лендинга.

## Установка

Распакуйте архив в корень проекта `Sali-VPN-main` с заменой файлов, затем выполните:

```powershell
npm install
npm run typecheck --workspace @sali/mobile
npm run android --workspace @sali/mobile
```

Для локальной работы API оставьте:

```env
EXPO_PUBLIC_API_URL=http://localhost:3000
EXPO_PUBLIC_LANDING_URL=https://salivpn.com
```

На Android-эмуляторе вместо `localhost` может понадобиться `10.0.2.2`.
